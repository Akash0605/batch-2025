JavaScript Definitions and Examples

1. Synchronous JavaScript

Definition: Runs code line by line.

Example:

    console.log('A');
    console.log('B');

Output: A B

2. Asynchronous JavaScript

Definition: Runs long tasks without blocking.

Example:

    console.log('Start');setTimeout(()=>console.log('Later'),1000);console.log('End');

Output: Start End Later

3. Event Loop

Definition: Executes queued async callbacks after sync code.

Example:

    console.log(1);setTimeout(()=>console.log(2),0);console.log(3);

Output: 1 3 2

4. JavaScript Callbacks

Definition: Function passed to another function.

Example:

    function f(cb){cb()} f(()=>console.log('Done'));

Output: Done

5. setTimeout()

Definition: Runs once after delay.

Example:

    setTimeout(()=>console.log('Hi'),1000);

Output: Hi

6. setInterval()

Definition: Runs repeatedly.

Example:

    let i=setInterval(()=>console.log('Hi'),1000);

Output: Hi…

7. clearTimeout()

Definition: Cancels timeout.

Example:

    let t=setTimeout(...);clearTimeout(t);

Output: No output

8. clearInterval()

Definition: Stops interval.

Example:

    let i=setInterval(...);clearInterval(i);

Output: Stopped

9. Strict Mode

Definition: Enables strict rules.

Example:

    "use strict"; x=5;

Output: ReferenceError

10. Garbage Collection

Definition: Removes unused memory.

Example:

    let a={};a=null;

Output: Object eligible

11. Memory Leaks

Definition: Unused memory retained.

Example:

    arr.push(new Array(1000));

Output: Memory grows

12. Debouncing and Throttling

Definition: Limit frequent function calls.

Example:

    debounce(search,300);

Output: One call

13. Execution Context

Definition: Environment for code execution.

Example:

    function test(){}

Output: Context created

14. Creating Date Objects

Definition: Create Date object.

Example:

    let d=new Date();

Output: Current date

30. charAt()

Definition: Returns character at index.

Example:

    "Java".charAt(1);

Output: a

31. charCodeAt()

Definition: Returns Unicode.

Example:

    "A".charCodeAt(0);

Output: 65

32. toUpperCase()

Definition: Uppercase string.

Example:

    "js".toUpperCase();

Output: JS

33. toLowerCase()

Definition: Lowercase string.

Example:

    "JS".toLowerCase();

Output: js

34. trim()

Definition: Removes spaces both ends.

Example:

    " hi ".trim();

Output: hi

35. trimStart()

Definition: Removes leading spaces.

Example:

    "hi ".trimStart();

Output: hi

36. trimEnd()

Definition: Removes trailing spaces.

Example:

    "hi ".trimEnd();

Output: hi

37. substring()

Definition: Extract by indexes.

Example:

    "Java".substring(1,3);

Output: av

38. substr()

Definition: Extract by start,length (deprecated).

Example:

    "JavaScript".substr(4,6);

Output: Script

39. repeat()

Definition: Repeats string.

Example:

    "Hi".repeat(3);

Output: HiHiHi

40. padStart()

Definition: Pads start.

Example:

    "7".padStart(3,"0");

Output: 007

41. padEnd()

Definition: Pads end.

Example:

    "JS".padEnd(5,".");

Output: JS…
